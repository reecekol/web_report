# Web Server Compromise Incident Response Case Study
A cybersecurity incident response case study involving the compromise of a WordPress web server.

### Overview
This project documents an investigation into a compromised WordPress web server following the exploitation of a vulnerable third-party plugin.
The investigation covers the identification of suspicious activity, reconstruction of the attack timeline, analysis of attacker behavior, persistence mechanisms, malware activity, website defacement, and the response actions taken to contain and remediate the incident.

The project demonstrates an end-to-end incident response process from ***detection through recovery and validation***.

###Key Areas
-Incident detection and triage
-Web server and application log analysis
-Attack timeline reconstruction
-Web application security
-Malware and web shell investigation
-Persistence analysis
-Vulnerability identification and remediation
-Incident containment and recovery
-Post-remediation validation
-Business and financial impact assessment
